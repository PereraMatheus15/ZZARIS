# Roadmap ZZARIS

## Evolução planejada

- **ZZARIS v0.1** → neurônios básicos
- **ZZARIS v0.2** → memória persistente
- **ZZARIS v0.3** → aprendizado contínuo
- **ZZARIS v0.4** → processamento de linguagem
- **ZZARIS v0.5** → assistente inteligente
- **ZZARIS v1.0** → núcleo cognitivo modular completo

## Próximos marcos

- Expandir o módulo `core.brain` com interpretação de linguagem natural.
- Adicionar reconhecimento de voz e comando por microfone.
- Integrar visão computacional simplificada com módulos de processamento de imagem.
- Criar adaptadores para controle de dispositivos ESP32.
- Desenvolver agentes autônomos baseados em objetivos e memória de longo prazo.
